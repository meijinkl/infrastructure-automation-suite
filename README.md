# Infrastructure Automation Suite

Комплексный проект, демонстрирующий навыки автоматизации инфраструктуры, контейнеризации, написания Bash-скриптов и настройки CI/CD пайплайнов.

## Стек технологий
*   **Конфигурация:** Ansible
*   **Контейнеризация:** Docker, Docker Compose
*   **Веб-сервер:** Nginx (HTTPS, SSL)
*   **Скриптинг:** Bash
*   **CI/CD:** GitHub Actions, GitLab CI

---

## Структура проекта и описание заданий

### 1. Настройка Nginx через Ansible (`/Nginx`)
В папке находится Ansible-плейбук для автоматической установки и настройки веб-сервера Nginx.
*   Используются переменные (`vars.yml`) и шаблоны Jinja2 (`templates/nginx_site.conf.j2`).
*   Плейбук обеспечивает установку пакета, копирование конфигурации, запуск сервиса и проверку его доступности.
*   В папке приложены логи успешного выполнения и проверки идемпотентности (`playbook-idempotent.log`).

### 2. Docker и Docker Compose для Nginx (`/Docker`)
Готовая среда для запуска Nginx в контейнере с поддержкой HTTPS.
*   **Dockerfile:** собирает образ, включая самоподписанный сертификат и ключ, а также конфигурацию.
*   **Конфигурация Nginx:** работает на порту 443, использует SSL-сертификат и перенаправляет HTTP (80) на HTTPS (443).
*   **Docker Compose:** обеспечивает автозапуск контейнера (`restart: always`), проброс портов и монтирование статической HTML-страницы из локальной директории как volume.

### 3. Мониторинг диска через Bash (`/Bash`)
Скрипт `monitor_disk.sh` для проверки занятого места на диске.
*   Если свободного места остается менее 15% (или занято более 85%), скрипт отправляет уведомление на почту.
*   Настройки SMTP-сервера параметризованы через файл `.env` (в репозитории есть шаблон `.env.example`, реальные пароли не хранятся в коде).

### 4. CI/CD Пайплайны
В проекте настроены пайплайны для обеих популярных платформ:
*   **GitHub Actions** (`.github/workflows/ci-cd.yml`)
*   **GitLab CI** (`.gitlab-ci.yml`)
*   Пайплайны включают этапы сборки (создание Docker-образа) и доставки (запуск контейнера).
